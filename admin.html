Admin sign-in

This page manages the designs on the rack. It only works with a GitHub access token that belongs to the site owner and can write to the repository, so nobody else can change anything here.

How do I get a token?
  1. Open github.com/settings/personal-access-tokens/new
  2. Name it something like SAPIENs admin and pick an expiration.
  3. Under Repository access choose Only select repositories → Sapiens.
  4. Under Permissions → Repository permissions set Contents to Read and write.
  5. Click Generate token, copy it, and paste it above.

The token is stored only in this browser and is sent only to GitHub. Anyone holding it can edit the repo, so don't share it — if it ever leaks, delete it on that same GitHub page.

Add designs

Drop design images here, or tap to choose Photos are fine — the background is removed for you, and you check the result before it's added. Images that already have a transparent background go straight in. Everything is trimmed and resized automatically.

New drop pop-up

Up to two reels that pop up on the shop. Each visitor sees it by itself once per drop, and a ● New drop button in the shop's menu bar replays it any time. Uploading new reels counts as a new drop, so everyone sees it once more.

MP4 works everywhere. iPhone tip: set Settings → Camera → Formats to Most Compatible, or save the reel from Instagram/CapCut as MP4. Up to 100 MB each; under 25 MB loads fast on phones.

On the rack

The first design faces the front when the shop loads. Use the arrows to reorder, edit names inline, and ✕ to remove. ✎ Front cleans up a shirt's photo; + Back adds a back side, and the shirt will turn on its hanger in the shop to show it. Nothing changes on the live site until you press Publish.
