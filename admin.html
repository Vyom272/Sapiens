Admin sign-in

This page manages the designs on the rack. It only works with a GitHub access token that belongs to the site owner and can write to the repository, so nobody else can change anything here.

How do I get a token?
  1. Open github.com/settings/personal-access-tokens/new
  2. Name it something like SAPIENs admin and pick an expiration.
  3. Under Repository access choose Only select repositories → Sapiens.
  4. Under Permissions → Repository permissions set Contents to Read and write.
  5. Click Generate token, copy it, and paste it above.

The token is stored only in this browser and is sent only to GitHub. Anyone holding it can edit the repo, so don't share it — if it ever leaks, delete it on that same GitHub page.

Add designs

Drop design images here, or tap to choose PNG or WebP with a transparent background (just the shirt) hangs best on the rack. Images are trimmed and resized automatically before upload.

On the rack

The first design faces the front when the shop loads. Use the arrows to reorder, edit names inline, and ✕ to remove. Add a back side to any design and it will turn on its hanger in the shop to show it. Nothing changes on the live site until you press Publish.
